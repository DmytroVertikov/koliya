# Колія: поездом из Украины и в Украину

Сайт на GitHub Pages + Supabase, четыре языка: RU (корень), UK, EN, PL (папки `uk/`, `en/`, `pl/`).

Публичный сайт читает варианты маршрутов из базы Supabase. Править их можно в админке `/admin/`. Страницы маршрутов и главная собираются из шаблонов скриптом `build.js`.

## Запуск (≈15 минут)

1. **База.** Создайте проект на supabase.com (бесплатно). Откройте SQL Editor и по очереди выполните файлы `schema.sql`, `seed.sql` (в нём уже загружены все маршруты) и `i18n.sql` (таблица текстов сайта, формы названий станций и тексты страниц маршрутов).
2. **Админ.** В Supabase: Authentication → Users → Add user (ваш email и пароль). Затем Authentication → Sign In / Providers → отключите **Allow new users to sign up**, иначе зарегистрироваться сможет любой.
3. **Ключи.** Project Settings → API. Скопируйте Project URL и anon public key в `config.js`. Эти ключи публичные, безопасность обеспечивают правила RLS из `schema.sql`.
4. **Сборка.** Установите Node.js и выполните `node build.js` (подробнее ниже).
5. **GitHub.** Создайте репозиторий `koliya`, загрузите все файлы из этой папки, откройте Settings → Pages → Source: Deploy from a branch → `main` / root.
6. Сайт будет по адресу `https://<ник>.github.io/koliya/`, админка по адресу `.../admin/`.

## Как устроена сборка

Готовые `.html` страницы **руками не правятся**: они создаются командой

```
node build.js
```

Все переводы лежат в базе и правятся в админке. `node sync.js` забирает их в файлы-снимки (`i18n.db.json`: тексты интерфейса и станции, `routes.db.json`: направления и тексты их страниц) и запускает `build.js`. Если базы не видно, берутся прежние снимки. Сборка берёт шаблоны `route.src.html` и `index.src.html`, переводы из снимков и список страниц из `routes.db.json` (таблица `route_pages`). Результат:

- `kyiv-warsaw.html`, `warsaw-kyiv.html`, `kyiv-krakow.html`, `krakow-kyiv.html` и `index.html` в корне (RU);
- те же страницы в `uk/`, `en/`, `pl/`;
- `dict/ru.js`, `dict/uk.js`, `dict/en.js`, `dict/pl.js`: словари для браузера (подключаются на страницах вместо прежнего `i18n.js`);
- `pages.js`: список страниц для браузера;
- `sitemap.xml`.

После правки переводов в админке, а также `route.src.html` или `index.src.html` запустите `node sync.js` (он же соберёт сайт) и загрузите изменённые файлы на GitHub. Если правите только `common.js` или `style.css`, пересборка не нужна.

Имена шаблонов должны быть ровно `route.src.html` и `index.src.html` (не `route_src.html`).

Версии вида `?v=…` в подключении `style.css` и скриптов больше не добавляются. После выкладки обновлений браузер или GitHub Pages могут несколько минут отдавать старые файлы: проверяйте через Ctrl+F5.

## Как править

- **Вариант маршрута** (админка). Одна строка, части разделяются `||`:
  `@ Киев 19:29 > Варшава 10:24 ; 14 ч 55 мин ; 1 пересадка || 019К: Киев 19:29 > *Хелм 05:00 || IC 12010: *Хелм 06:34 > Люблин 07:44 > *Варшава Центральная 10:15`
  - `@ …` шапка карточки: откуда > куда ; в пути (необязательно) ; плашка (необязательно);
  - дальше каждый поезд отдельной частью, станции через `>`, звёздочка `*` выделяет станцию крупным шрифтом;
  - пересадка между поездами добавляется автоматически. Админка проверяет формат прямо при вводе.
- **Скрыть поезд**, не удаляя: «Показывать: Скрыт».
- **Новая страна:** админка поездов → вкладка «Страны» (код, флаг, названия на четырёх языках, падежи для главной), затем «Пересобрать сайт», затем «Направления» → «Новое направление».
- **Тексты сайта и переводы:** админка поездов (`/admin/trains.html`), вкладка «Тексты». Одна строка на ключ, колонки ru / uk / en / pl; пустой перевод заменяется русским. Названия стран правятся во вкладке «Страны» (они хранятся в `ui_texts` под ключами `cn.<код>` и `cn.<код>.gen`).
- **Тексты страницы маршрута** (заголовок, описание, подзаголовок и т.д.): вкладка «Направления» → «Редактировать».
- **Название станции на другом языке** и формы «в Хелме» / «у Хелмі» / «w Chełmie»: вкладка «Станции». Без перевода станция показывается по-русски (в консоли браузера появится сообщение).
- Сайт получает изменения после нажатия «Пересобрать сайт» в админке (запускает GitHub Actions: `.github/workflows/rebuild.yml` делает `node sync.js` и коммитит результат), обычно через 1–2 минуты. Вручную то же самое: `node sync.js` и загрузка файлов на GitHub.

## Популярные маршруты на главной

В блоке «Популярные маршруты» у каждой страны сразу видны только страницы с галочкой «на главной» (админка поездов → «Направления»), остальные лежат в раскрывающемся списке. Если у страны нет ни одной отмеченной страницы, показываются все её маршруты. Хранится в `route_pages.popular`, на сайте после «Пересобрать сайт».

## Пометки у поездов

Пометка рядом с номером поезда выбирается в админке: «Поезда» → поезд → поле «Пометка» (сидячий интерсити, по нечётным числам, по чётным числам). Хранится в `trains.badge`, на сайт попадает после «Пересобрать сайт» через `pages.js` (`CFG.TRAIN_BADGES`). Тексты пометок лежат в `ui_texts` под ключами `seat`, `odd`, `even`. Новый вид пометки (кроме этих трёх) требует кода: ограничение `trains_badge_check` в базе, иконка `ICON` в `common.js` и стиль в `style.css`.

## Пограничный контроль

Для страниц Киев → Краков и Краков → Киев под плашкой пересадки в Перемышле выводится строка про пограничный контроль. Она включается флагом `border` в `ROUTES` в `build.js`:

- `border: "after"`: «После прибытия в Перемышль происходит пограничный контроль» (Киев → Краков);
- `border: "before"`: «Перед отправлением из Перемышля происходит пограничный контроль» (Краков → Киев).

Тексты лежат во вкладке «Тексты» под ключами `border.after` и `border.before`. Без флага строка на странице не выводится.

## Новая страница маршрута

Создаётся в админке: «Поезда» → вкладка «Направления» → «Новое направление» (сразу две страницы: туда и обратно, на четырёх языках). Параметры блока покупки и тексты страницы правятся там же («Изменить»). Затем `node sync.js` и загрузка файлов на GitHub. Адрес страницы попадёт в `sitemap.xml` и на главную автоматически, править `build.js` и `config.js` не нужно.

## Файлы

- `index.src.html`, `route.src.html`: шаблоны главной и страниц маршрутов;
- `build.js`: сборка языковых версий, словарей `dict/` и `sitemap.xml`;
- `sync.js`: выгрузка направлений, текстов и станций из базы и запуск сборки;
- `pages.js`: список страниц маршрутов (создаётся сборкой, руками не править);
- `i18n.db.json`, `routes.db.json`: снимки данных из базы (создаются `sync.js`);
- `dict/`: словари для браузера (результат сборки);
- `common.js`: общий код (разбор формата вариантов, карточки, пометки поездов, футер);
- `style.css`: оформление;
- `config.js`: ключи Supabase;
- `index.html`, `uk/`, `en/`, `pl/`, `kyiv-warsaw.html` и другие страницы маршрутов, `sitemap.xml`: результат сборки;
- `admin/trains.html`: админка (страны, направления, поезда, варианты, станции, тексты); `admin/index.html` только перенаправляет на неё;
- `schema.sql`, `seed.sql`, `i18n.sql`: база.
