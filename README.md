# Колія: поездом из Украины и в Украину

Сайт на GitHub Pages + Supabase, четыре языка: RU (корень), UK, EN, PL (папки `uk/`, `en/`, `pl/`).

Публичный сайт читает варианты маршрутов из базы Supabase. Править их можно в админке `/admin/`. Страницы маршрутов и главная собираются из шаблонов скриптом `build.js`.

## Запуск (≈15 минут)

1. **База.** Создайте проект на supabase.com (бесплатно). Откройте SQL Editor и по очереди выполните файлы `schema.sql`, затем `seed.sql` (в нём уже загружены все маршруты).
2. **Админ.** В Supabase: Authentication → Users → Add user (ваш email и пароль). Затем Authentication → Sign In / Providers → отключите **Allow new users to sign up**, иначе зарегистрироваться сможет любой.
3. **Ключи.** Project Settings → API. Скопируйте Project URL и anon public key в `config.js`. Эти ключи публичные, безопасность обеспечивают правила RLS из `schema.sql`.
4. **Сборка.** Установите Node.js и выполните `node build.js` (подробнее ниже).
5. **GitHub.** Создайте репозиторий `koliya`, загрузите все файлы из этой папки, откройте Settings → Pages → Source: Deploy from a branch → `main` / root.
6. Сайт будет по адресу `https://<ник>.github.io/koliya/`, админка по адресу `.../admin/`.

## Как устроена сборка

Готовые `.html` страницы **руками не правятся**: они создаются командой

```
node build.js
```

Скрипт берёт шаблоны `route.src.html` и `index.src.html`, тексты из `i18n.js` и список страниц из `ROUTES` в `build.js`. Результат:

- `kyiv-warsaw.html`, `warsaw-kyiv.html`, `kyiv-krakow.html`, `krakow-kyiv.html` и `index.html` в корне (RU);
- те же страницы в `uk/`, `en/`, `pl/`;
- `sitemap.xml`.

После любой правки `build.js`, `route.src.html`, `index.src.html` или `i18n.js` запустите сборку и загрузите изменённые файлы на GitHub. Если правите только `common.js`, `style.css` или `config.js`, пересборка не нужна.

Имена шаблонов должны быть ровно `route.src.html` и `index.src.html` (не `route_src.html`).

Версии вида `?v=…` в подключении `style.css` и скриптов больше не добавляются. После выкладки обновлений браузер или GitHub Pages могут несколько минут отдавать старые файлы: проверяйте через Ctrl+F5.

## Как править

- **Вариант маршрута** (админка). Одна строка, части разделяются `||`:
  `@ Киев 19:29 > Варшава 10:24 ; 14 ч 55 мин ; 1 пересадка || 019К: Киев 19:29 > *Хелм 05:00 || IC 12010: *Хелм 06:34 > Люблин 07:44 > *Варшава Центральная 10:15`
  - `@ …` шапка карточки: откуда > куда ; в пути (необязательно) ; плашка (необязательно);
  - дальше каждый поезд отдельной частью, станции через `>`, звёздочка `*` выделяет станцию крупным шрифтом;
  - пересадка между поездами добавляется автоматически. Админка проверяет формат прямо при вводе.
- **Скрыть поезд**, не удаляя: «Показывать: Скрыт».
- **Новая страна:** раздел «Страны», затем «+ Новое направление» (коды вида `ua-sk` и `sk-ua`, это формат ссылки).
- **Тексты сайта и переводы:** `i18n.js`. Блоки `ru`, `uk`, `en`, `pl` с ключами интерфейса, словарь станций `ST` (название по-русски → переводы и формы «в Хелме»), словарь стран `CN`. Если в блоке язык повторяется ключ, действует последний; `build.js` предупредит об этом.
- **Название станции на другом языке:** добавьте её в `ST` в `i18n.js`. Без записи станция показывается по-русски (в консоли браузера появится сообщение).

## Пометки у поездов

В `common.js` есть список `TRAIN_BADGES`: номер поезда → пометка рядом с названием поезда.

```js
const TRAIN_BADGES = {
    seat: ["705К", "715К"],   // «Сидячий интерсити»
    odd:  ["070О"],           // «Ходит по нечётным числам»
    even: ["070К"]            // «Ходит по чётным числам»
};
```

Буква в номере кириллическая; латинские `K` и `O` тоже сработают, регистр, пробелы и ведущие нули не важны. Чтобы добавить поезд, допишите его номер в нужный список. Для новой пометки добавьте ключ с текстом во все четыре языка в `i18n.js`, иконку в `ICON` и, при необходимости, стиль `.tb.<ключ>` в `style.css`.

## Пограничный контроль

Для страниц Киев → Краков и Краков → Киев под плашкой пересадки в Перемышле выводится строка про пограничный контроль. Она включается флагом `border` в `ROUTES` в `build.js`:

- `border: "after"`: «После прибытия в Перемышль происходит пограничный контроль» (Киев → Краков);
- `border: "before"`: «Перед отправлением из Перемышля происходит пограничный контроль» (Краков → Киев).

Тексты лежат в `i18n.js` под ключами `border.after` и `border.before`. Без флага строка на странице не выводится.

## Новая страница маршрута

1. Добавьте запись в `ROUTES` в `build.js`: `id`, `file`, `FROM` и `TO` (русские названия, как в шапке карточки в админке), `BACK` и `hash` (коды направлений, например `ua-pl` и `pl-ua`), `rev` (файл обратного маршрута), `uz` и `pkp` (пары станций для кнопок покупки), `t3`, при пересадке не в Хелме `x`, для маршрута без прямого поезда `direct: false`, при необходимости `border`.
2. В `i18n.js` во всех четырёх языках добавьте ключи `<id>.title`, `<id>.desc`, `<id>.h1`, `<id>.lead`, `<id>.all`, `<id>.more`.
3. Добавьте страницу в `PAGES` в `config.js` (так она появится на главной и на странице направления).
4. Запустите `node build.js`. Адрес страницы попадёт в `sitemap.xml` автоматически.

## Файлы

- `index.src.html`, `route.src.html`: шаблоны главной и страниц маршрутов;
- `build.js`: сборка языковых версий и `sitemap.xml`;
- `i18n.js`: тексты и словари на всех языках;
- `common.js`: общий код (разбор формата вариантов, карточки, пометки поездов, футер);
- `style.css`: оформление;
- `config.js`: ключи Supabase и список страниц маршрутов (`PAGES`);
- `index.html`, `uk/`, `en/`, `pl/`, `kyiv-warsaw.html` и другие страницы маршрутов, `sitemap.xml`: результат сборки;
- `admin/index.html`: админка;
- `schema.sql`, `seed.sql`: база.
