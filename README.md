# Колія: поездом из Украины и в Украину

Сайт на GitHub Pages + Supabase.

Публичный сайт читает маршруты из базы Supabase. Править их можно в админке `/admin/`.

## Запуск (≈15 минут)

1. **База.** Создайте проект на supabase.com (бесплатно). Откройте SQL Editor и по очереди выполните файлы `schema.sql`, затем `seed.sql` (в нём уже загружены все маршруты).
2. **Админ.** В Supabase: Authentication → Users → Add user (ваш email и пароль). Затем Authentication → Sign In / Providers → отключите **Allow new users to sign up**, иначе зарегистрироваться сможет любой.
3. **Ключи.** Project Settings → API. Скопируйте Project URL и anon public key в `config.js`. Эти ключи публичные, безопасность обеспечивают правила RLS из `schema.sql`.
4. **GitHub.** Создайте репозиторий `koliia`, загрузите все файлы из этой папки, откройте Settings → Pages → Source: Deploy from a branch → `main` / root.
5. Сайт будет по адресу `https://<ник>.github.io/koliya/`, админка по адресу `.../admin/`.

## Как править

- **Вариант маршрута:** `019: Киев 19:06 > Хелм 05:00||IC 12010: Хелм 06:22 > Варшава 09:43`. Каждая часть до `||` это отдельный поезд, пересадка добавляется автоматически. Админка проверяет формат прямо при вводе.
- **Скрыть поезд**, не удаляя: поставьте «Показывать: Скрыт».
- **Новая страна:** раздел «Страны», затем «+ Новое направление» (коды вида `ua-sk` и `sk-ua`, это формат ссылки).

## Файлы
`index.html` публичный сайт · `admin/index.html` админка · `common.js` общий разбор формата · `style.css` оформление · `config.js` ключи · `schema.sql`, `seed.sql` база.
